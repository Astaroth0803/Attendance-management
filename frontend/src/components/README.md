# Components Module

## Descripción
El directorio `components` contiene los componentes reutilizables de la interfaz de usuario de Vue (elementos de interfaz, layouts, menús) que se pueden ensamblar en distintas vistas (`views`).

## Archivos Principales
- **AppLayout.vue**: El componente principal de diseño (layout temporal/permanente) que agrupa la estructura base (barra de navegación, menú lateral, pie de página) para renderizar el contenido anidado de la plataforma.
- Componentes modulares, botones, y tarjetas.
