# Views Module

## Descripción
El directorio `views` almacena los componentes de nivel de página (page-level components). Mientras que los archivos en `components` son elementos aislados, las páginas en `views` representan rutas completas a las que el usuario puede acceder.

## Estructura
- Contiene archivos Vue específicos para cada sección importante del sistema (como un listado de beneficiarios, vista de asistencia, dashboard, etc.).
- Cada `.vue` aquí suele ser mapeado en la configuración del directorio `router`.
