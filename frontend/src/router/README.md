# Router Module

## Descripción
El directorio `router` maneja la configuración de rutas (Vue Router) para establecer la navegación del Single Page Application (SPA).

## Funciones
- Mapea las URLs del navegador web con sus respectivos componentes definidos en el directorio `views`.
- Implementa guardias de navegación (navigation guards) si es necesario proteger rutas requiriendo autenticación previa o un rol específico.
